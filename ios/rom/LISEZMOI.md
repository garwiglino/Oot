# Placez votre ROM ici

Copiez **une seule** ROM Ocarina of Time dans ce dossier, sur votre Mac (`.z64`, `.n64` ou `.v64`,
non compressée), puis lancez `./ios/build.sh`.

Ce dossier est ignoré par Git : la ROM ne sera jamais envoyée sur GitHub. Ne la déplacez pas ailleurs
dans le dépôt, qui est public.
